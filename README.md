# BE Virtual Lab

Interactive, browser-based virtual labs for Basic Electronics (BE). No installation needed. Open a link and start experimenting.

**Live site:** https://akhendrakumar-arch.github.io/virtual-lab/

## Labs

| Lab | What you learn |
|-----|----------------|
| [Resistor Coding, KCL/KVL & Virtual Breadboard](https://akhendrakumar-arch.github.io/virtual-lab/) | Read resistor colour codes, verify Kirchhoff's Current and Voltage Laws, and build circuits on a Tinkercad-style breadboard |
| [Zener Diode — Interactive Lesson & Regulator Lab](https://akhendrakumar-arch.github.io/virtual-lab/zener-diode-lab.html) | Zener breakdown, V–I characteristics, and designing a voltage regulator |
| [Semiconductor & PN Junction Diode](https://akhendrakumar-arch.github.io/virtual-lab/pn-junction-lab.html) | Animated view of semiconductors, depletion region, and forward/reverse bias of a PN junction |

## Usage

Works in any modern browser on desktop or mobile. Each lab is a single self-contained HTML page.
